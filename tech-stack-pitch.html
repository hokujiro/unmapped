Identity & locale

Country ID, UI language, and script. Swap this and every string in the UI localises automatically.

🗂

Taxonomy wiring

Maps local education levels to ISCED; plugs ESCO, ISCO-08, and O*NET into the skill and task pipelines.

📡

Live labour signals

Points each API at the right ILOSTAT/WDI series for this country. Wage and employment data refresh without a redeploy.

⚡

Risk calibration

Selects the AI-exposure and automation baselines, then applies digital-access discounts specific to local infrastructure.

🔌

Job connectors & policy

CSV uploads, API feeds, or live crawl via Tavily. Policy overlays (e.g. WBL gender index) layer on top without touching core logic.
